# M1 - Docs and Onboarding

Goal: let a new contributor clone, run, and submit a first PR in under 30 minutes.

## Issue-sized tasks

- [ ] Rewrite backend README with project-specific setup and run steps.
  - Scope: replace starter template content.
  - Done when: a contributor can run backend from README only.

- [ ] Add a root quick-start section in main README.
  - Scope: prerequisites, install, codegen, build, test.
  - Done when: monorepo bootstrap is documented in one place.

- [ ] Add environment variable reference for backend.
  - Scope: variable name, default, required/optional, sample values.
  - Done when: no hidden env assumptions remain.

- [ ] Add troubleshooting docs for common build/cache/codegen issues.
  - Scope: turbo cache misses/hits, stale generated outputs, clean rebuild command.
  - Done when: known recurring issues are self-service.

- [ ] Create CONTRIBUTING guide.
  - Scope: branching, commit style, PR checklist, testing expectations.
  - Done when: external contributors have a clear contribution contract.
