# M6 - Governance and Community

Goal: make project collaboration sustainable as external contributor count grows.

## Issue-sized tasks

- [ ] Add issue templates for bug reports and feature requests.
  - Scope: reproduction info, environment details, expected behavior.
  - Done when: maintainers receive actionable issue reports.

- [ ] Add pull request template.
  - Scope: change summary, test evidence, breaking-change checklist.
  - Done when: reviews are faster and more consistent.

- [ ] Define CODEOWNERS or ownership boundaries.
  - Scope: map packages/areas to maintainers.
  - Done when: review routing is automated.

- [ ] Publish release/versioning guidance for workspace packages.
  - Scope: when to bump, changelog expectations, release flow.
  - Done when: contributors understand compatibility impact.

- [ ] Document support channels and triage expectations.
  - Scope: response times, priorities, communication paths.
  - Done when: community interaction is predictable.
